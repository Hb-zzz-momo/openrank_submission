## 5. 图表分类建议

### 5.1 排名与对比类

用于回答：“谁最强？谁增长最快？不同项目差距多大？”

可放：

1. **横向柱状图 Bar Chart**：项目综合健康度排名。
2. **堆叠柱状图 Stacked Bar Chart**：不同指标对总分的贡献。
3. **棒棒糖图 Lollipop Chart**：更轻量的排名对比。
4. **坡度图 Slope Chart**：两个月或两年之间排名变化。
5. **子弹图 Bullet Chart**：项目得分与目标值、均值、行业线对比。

适合当前页面已有的 Top N 排行榜继续扩展。

---

### 5.2 趋势变化类

用于回答：“项目是不是变热了？活跃度是否持续上升？”

可放：

1. **折线图 Line Chart**：OpenRank 均值、活跃度均值趋势。
2. **面积图 Area Chart**：多项目累计活跃度变化。
3. **流图 Streamgraph**：不同类别项目热度占比随时间变化。
4. **日历热力图 Calendar Heatmap**：每日提交、Issue、PR 活动强度。
5. **Bump Chart 排名流动图**：项目排名随月份变化。

---

### 5.3 结构层级类

用于回答：“LLM 生态内部结构是什么样？哪些类别占主导？”

这里可以放你说的“核爆图”。更标准的名字建议叫：

**旭日图 Sunburst Chart**：用同心圆展示层级结构，例如：

```text
LLM生态
├── 训练框架
│   └── pytorch
├── 推理引擎
│   ├── vLLM
│   ├── TensorRT-LLM
│   └── ollama
├── 向量数据库
│   └── milvus
└── 低代码平台
    └── dify
```

可放：

1. **旭日图 Sunburst Chart**：类别 → 项目 → 指标贡献。
2. **矩形树图 Treemap**：用面积表达项目影响力。
3. **圆堆图 Circle Packing**：展示生态层级和项目规模。
4. **冰柱图 Icicle Chart**：横向展示层级路径。
5. **树图 Tree Chart**：展示技术生态分类树。

---

### 5.4 关系网络类

用于回答：“项目之间、组织之间、贡献者之间有什么关系？”

可放：

1. **力导向图 Force-directed Graph**：项目、组织、贡献者之间的关系网络。
2. **依赖关系图 Dependency Graph**：项目之间的依赖关系。
3. **二分图 Bipartite Graph**：开发者 ↔ 项目、组织 ↔ 项目。
4. **弦图 Chord Diagram**：不同类别之间的贡献流动。
5. **桑基图 Sankey Diagram**：贡献者 → 组织 → 项目 → 生态类别的流向。

这部分很适合体现 OpenRank 的“生态分析”深度。

---

### 5.5 多指标评估类

用于回答：“一个项目是均衡发展，还是某一项特别强？”

可放：

1. **雷达图 Radar Chart**：健康度、活跃度、协作度、社区成熟度、增长性。
2. **平行坐标 Parallel Coordinates**：多个项目在多个指标上的综合对比。
3. **散点图 Scatter Plot**：OpenRank 均值 × 活跃度均值。
4. **气泡图 Bubble Chart**：横轴健康度，纵轴活跃度，气泡大小表示 Star、Fork 或贡献者数。
5. **四象限图 Quadrant Chart**：高健康高活跃、低健康高活跃等分区。

---

### 5.6 风险与异常类

用于回答：“哪些项目可能衰退？哪些项目短期异常活跃？”

可放：

1. **异常点检测图 Anomaly Chart**：发现活跃度突然上涨或下降。
2. **箱线图 Box Plot**：比较不同类别项目指标分布。
3. **小提琴图 Violin Plot**：展示健康度分布密度。
4. **热力矩阵 Matrix Heatmap**：项目 × 指标的强弱对比。
5. **漏斗图 Funnel Chart**：从关注、贡献、合并、发布的转化链路。

## 6. 推荐的页面视觉风格

你当前页面已经是：

```text
深色背景 + 蓝紫渐变 + 绿色数据视觉 + 卡片式布局
```

新增页面建议继续保持这个风格，但要做三点增强：

### 6.1 不要所有图都直接渲染

否则页面会非常卡，也很乱。建议：

```text
默认展示图表缩略卡片
点击后再加载真实图表
```

每张卡片包含：

```text
图表名称
图表类型
适合回答的问题
需要的数据字段
推荐使用场景
查看大图按钮
收藏按钮
```

示例：

```text
┌──────────────────────┐
│ 旭日图 Sunburst       │
│ 用途：查看生态层级结构 │
│ 字段：category/project │
│ 适合：类别占比分析     │
│ [查看大图] [收藏]      │
└──────────────────────┘
```

---

### 6.2 页面采用“两种模式”

#### 模式一：图表总览模式

适合浏览所有图。

```text
左侧分类 + 中间图表卡片网格 + 右侧说明
```

#### 模式二：大图分析模式

适合认真分析某一个图。

```text
左侧参数配置
中间大图
右侧 AI 洞察 / 数据解释 / 导出按钮
```

---

### 6.3 每个图表都要配“分析问题”

不要只写“热力图”“桑基图”，而是写成：

```text
这个图能回答什么问题？
```

例如：

| 图表    | 页面上建议写法             |
| ----- | ------------------- |
| 热力图   | 哪些项目在哪些指标上表现突出？     |
| 旭日图   | LLM 生态的类别结构是否均衡？    |
| 桑基图   | 贡献者、组织、项目之间的贡献流向如何？ |
| 关系图   | 哪些项目处在生态网络中心？       |
| 雷达图   | 项目的综合能力是否均衡？        |
| 散点气泡图 | 高活跃项目是否也具有高健康度？     |

这样用户更容易理解图表价值。

## 11. 工程落地设计契约

Reading this as: 数据产品中的“图表库 + 分析工作台”页面，服务开源生态分析者、项目选型者和评审展示者，视觉语言延续 OpenRank 深色数据实验室，信息密度高但操作边界清晰。

- `DESIGN_VARIANCE`: 7
- `MOTION_INTENSITY`: 4
- `VISUAL_DENSITY`: 8

### 11.1 Visual Theme & Atmosphere

页面应像一个可操作的数据工坊，而不是营销落地页。整体气质是深色、冷静、专业、实验室感，第一屏直接呈现筛选器、图表分类、图表卡片和洞察面板。视觉重点落在“可筛选、可进入大图、可导出、可收藏”的工作台能力上。

### 11.2 Color Palette & Roles

基础背景使用接近 `#07111f` 的深蓝黑，主面板使用半透明深色表面。青色和绿色只作为数据高亮与操作反馈，粉红/琥珀用于风险和异常提示。避免整页被紫蓝渐变主导，渐变只能作为局部数据动势和页背景层次。

### 11.3 Typography Rules

页面只保留一个主标题。图表卡片标题控制在 16-18px，面板标题控制在 20px 左右，说明文字使用 12-15px 的紧凑层级。所有中文说明必须是真实业务问题，不能写空泛功能口号。

### 11.4 Component Stylings

全局筛选区使用紧凑表单控件。图表卡片必须包含图表类型、图表名、分析问题、缩略视觉和分类标签。左侧分类使用按钮列表，右侧洞察使用条目式说明。大图分析模式使用三栏工作台：参数、图表、洞察/导出。

### 11.5 Layout Principles

默认是总览模式：左侧分类导航，中间图表卡片网格，右侧说明与洞察。点击图表后进入大图分析模式，不在首屏同时渲染全部重型图表。桌面优先呈现三栏，平板折叠右侧面板，移动端单列堆叠。

### 11.6 Depth & Elevation

使用边框、透明度和轻量阴影区分层级。卡片半径保持 8px，避免卡片套卡片和厚重毛玻璃。大图弹层使用深色遮罩和清晰三栏边界，保证它像工作台而不是装饰弹窗。

### 11.7 Animation & Interaction

动效以 hover、focus、卡片轻微上移、加载骨架为主。ECharts 交互交给图表自身的 tooltip、legend、roam 和 emphasis。必须支持键盘打开图表、关闭弹窗、表单 focus 可见。

### 11.8 Do's and Don'ts

Do: 用注册表管理图表；懒加载趋势数据；提供 loading、empty、error；将收藏和导出纳入主流程；每张图都绑定“能回答的问题”。

Don't: 把所有真实图表同时铺满页面；做空洞大 hero；依赖单一紫蓝渐变；只展示成功态；把未登录收藏静默失败。

### 11.9 Responsive Behavior

桌面 `>=1180px` 使用三栏工坊和三栏大图工作台。`760px-1180px` 图表总览保留左侧分类和主内容，洞察面板下移。`<760px` 所有区域单列，筛选器全宽，卡片最小宽度取消，大图弹层改为可滚动纵向工作台。
